01-portfolio-webgl.png
  Title: Mindulle Atelier — WebGL Portfolio
  Description: A scroll-driven 3D portfolio built with Three.js. Four acts — threshold, rain,
  dandelion, release — each a low-poly scene with its own light and ambience. Korean editorial
  typography sits over the WebGL canvas while scroll drives the camera.

02-blog-editorial.png
  Title: Mindulle Garden — Editorial Blog
  Description: An editorial system for a personal blog. Masthead, volume markers and a two-column
  dispatch grid share one type scale; posts are generated from MDX so hierarchy cannot drift
  between articles.

03-packaging-label.png
  Title: Sonagi Tea — Print-Ready Label
  Description: Label system for a Korean green tea. Front and side panels are defined as a data
  contract and rendered with 3mm bleed, CMYK separation, crop marks and a reserved barcode quiet
  zone — press-ready without a redesign loop.

04-identity-system.png
  Title: Sonagi — Identity System
  Description: A quiet identity built on one mark and a single terracotta accent. Logo
  construction, colour and type are set as eight plates with clear space and minimum size defined
  for print, app icon and signage.

05-design-tokens.png
  Title: Design Tokens — Two Themes, One Contract
  Description: Eight primitive scales and two semantic themes compiled from one JSON source to CSS
  variables and Figma Variables. Design and code read the same contract.

06-studio-collateral.png
  Title: Studio Collateral — Cross-Format Typography
  Description: Banner system for X, LinkedIn and 99designs. Wordmark, rule and accent hold their
  place while the ratio shifts from 3:1 to 6.2:1.
