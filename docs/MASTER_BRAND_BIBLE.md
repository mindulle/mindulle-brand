## Chapter 01. Brand Soul & Visual Identity Charter (최상위 시각 정체성 헌법)

### 1.1. 우리의 본질 (Core Manifesto)

> **"민들레는 현대적인 소프트웨어 엔지니어링 공방이자,  
> 잉크 냄새와 종이의 물성이 살아 숨 쉬는 단단한 지면, 「민들레 정원 (Mindulle Garden)」이다."**

우리는 가상의 판타지 세계관이나 박물관 롤플레잉을 하지 않습니다.  
우리는 **Everything as Code**, W3C 디자인 토큰, 견고한 TypeScript/Next.js 기반으로 실전 프로덕트를 짓는 엔지니어이자 디자이너입니다.  
우리의 시각적 표현은 **「신문지(Newsprint) 활판 인쇄술(Letterpress)」**의 정갈함과 지적 신뢰성에 뿌리를 둡니다.

---

### 1.2. 85:15 조형 헌법 (The 85:15 Rule)

소나기·민들레 생태계의 모든 화면과 그래픽은 다음의 황금비율을 엄격히 준수합니다:

```
┌─────────────────────────────────────────────────────────────┐
│ [ 85% 시스템 골격 ] : 신문 브로드시트 & 활판 인쇄 모더니즘   │
│  • 1px / 2px 단단한 헤어라인 실선 (The True 2px Stem)       │
│  • 신문 칼럼 그리드, 단정한 세리프(Cormorant/마루부리) 위계   │
│  • 갓 인쇄된 잉크 블랙(#161616) & 미색 신문용지(#FBF9F5)     │
├─────────────────────────────────────────────────────────────┤
│ [ 15% 그래픽 악센트 ] : 절제된 민들레 보태니컬 에칭 (선화)   │
│  • 신문 칼럼 구석에 단색(1도)으로 정교하게 인쇄된 펜화      │
│  • 민들레 싹(Sprout), 씨앗(Golden Seed), 기사 종결 부호(❦)  │
└─────────────────────────────────────────────────────────────┘
```

* **85%의 골격**: 시스템을 지배하는 것은 장식이 아닌 **이성적이고 단단한 신문 조판 그리드**입니다.
* **15%의 악센트**: 민들레의 생명력은 화면을 휘감는 장식이 아니라, **정교한 1도 펜 선화 스팟 삽화(Spot Illustration / Vignette)**로만 절제되어 존재합니다.

---

### 1.3. 절대 금지 안티패턴 (Strict Anti-Patterns)

1. **❌ 전면적 아르누보(Art Nouveau) 덩굴 장식 금지**:
   * 화면 전체를 휘감는 구불구불한 식물 테두리, 금박 그라디언트, 아르누보풍 여신/꽃 장식 절대 금지. (타로카드 숍, 판타지 게임, 빈티지 찻집화 원천 차단)
2. **❌ 과도한 가상 롤플레잉/박물관 놀이 금지**:
   * 라틴어 학명 표기, 가상 식물도감 번호, 채집지/서식지 롤플레잉, 가상 압인 씰 철거.
3. **❌ 스크린 가독성을 침범하는 텍스처 필터 금지**:
   * 활자를 흐리게 만드는 과도한 SVG FeTurbulence 필터나 무거운 질감 타일링 금지. 가독성은 텍스처보다 항상 우선합니다.
4. **❌ 소프트 드롭 섀도우 및 네온 컬러 금지**:
   * 물리적 인쇄물에는 블러 처리된 그림자가 없습니다. 단단한 2px 경계선과 Crisp Shadow만 허용합니다.

### 2.1. 인장의 5대 구조 요소 (Anatomy Elements)
1. **기저 디스크 (Base Disc, R192)**:
   - 배경: `#060911` (Deep Obsidian Black)
   - 방사형 오라: `#ffd166` (18% 중심) ➔ `#4A90E2` (12% 중간) ➔ `#00ffcc` (4% 외곽).
2. **이중 건축 외벽 링 (Double Structural Rings)**:
   - 제1외벽: 반지름 188px, `stroke: #30363d`, `strokeWidth: 2px` (절대 성벽).

3. **8각 크리스탈 유리 패싯 (Octagonal Glass Dome Facets)**:

4. **민들레 황금 홀씨 코어 (Dandelion Gold Core)**:

5. **원호 타이포그래피 (Arched Lettering)**:
   - 상단 호(Upper Arc, R146): `MINDULLE STUDIO` (Cormorant Garamond 700, 21px, 자간 0.28em, `#ffffff`).
   - 하단 호(Lower Arc, R142): `• SOUL & HARNESS • EST. 2026 •` (JetBrains Mono 600, 10px, 자간 0.22em, `#ffd166`).
   - 양측 8각 분리 스타(Separator Stars): 좌표 `(50,200)` 및 `(350,200)` 골드 스타.

## Chapter 03. The Trinity Lockup Formulas (수학적 락업 공식)

스튜디오 마스터 인장과 하위 제품군 BI는 임의의 크기로 조합될 수 없으며, 반드시 아래 **수학적 황금비 락업 공식**에 따라 결합됩니다.

### 3.1. 마스터 가로형 락업 (Primary Horizontal Lockup)
*웹사이트 글로벌 네비게이션(GNB), 공식 문서 레터헤드, 프레젠테이션 타이틀용.*

```
 ┌─── 1.0D ───┐   0.25D   ┌─────────────── 2.2D ───────────────┐
 ┌────────────┐     │     M I N D U L L E   S T U D I O        ▲ 0.35D
 │            │     │     ───────────────────────────────────  │ 2px Divider
 │  [ ATELIER │    2px    S O N A G I   E C O S Y S T E M      ▼ 0.25D
 │    SEAL ]  │  Divider  [ Product BI : VectorCraft ]         ▼ 0.20D
 │            │     │
 └────────────┘     │
```

- **기준 단위 ($D$)**: 아틀리에 인장의 지름 ($D$).
- **인장과 텍스트 간격**: $0.25D$.
- **디바이더 라인(Divider)**: 폭 2px 솔리드, 높이 $0.6D$, 색상 `#30363d`.
- **텍스트 블록 높이**:
  - Main Title (`MINDULLE STUDIO`): Cap-height = $0.28D$ (`Cormorant Garamond Bold`).
  - Sub Title (`SONAGI ECOSYSTEM`): Cap-height = $0.14D$ (`JetBrains Mono SemiBold`).
  - Product Callout (`VectorCraft`): Cap-height = $0.14D$ (`Pretendard Bold`, Color `#4A90E2`).

### 3.2. 마스터 세로형 락업 (Primary Vertical / Centered Lockup)
*모바일 스플래시 화면, 제품 패키지 전면, 인증서, 파비콘 확장형.*

```
              ┌──────── 1.0D ────────┐
              │                      │
              │    [ ATELIER SEAL ]  │  1.0D
              │                      │
              └──────────────────────┘
                         │
                         ▼ Gap = 0.25D
              MINDULLE STUDIO          (0.25D)
              ───────────────────      (2px Divider, Width = 0.8D)
              SOUL & HARNESS           (0.12D)
```

*「민들레 정원 (Mindulle Garden)」 신문 지면 상단 헤더, 공식 발행물 레터헤드용.*

## Chapter 04. Clearspace & Optical Minimum Sizing Rules

### 4.1. 1X 안전 여백 공식 (The 1X Clearspace Rule)
로고와 인장의 시각적 존엄을 지키기 위해, 사방에 어떠한 텍스트, 경계선, 다른 그래픽도 침범할 수 없는 **무균실(Exclusion Zone)**을 유지합니다.

```
       ┌──────────────────────── 1X ────────────────────────┐
       │                                                    │
  ┌─── │ ┌────────────────────────────────────────────────┐ │ ───┐
  │    │ │                                                │ │    │
  │    │ │                                                │ │    │
 1X    │ │             [ LOGO / SEAL ASSET ]              │ │   1X
  │    │ │                                                │ │    │
  │    │ │                                                │ │    │
  └─── │ └────────────────────────────────────────────────┘ │ ───┘
       │                                                    │
       └──────────────────────── 1X ────────────────────────┘
```

- **안전 여백 기준값 ($X$)의 수학적 정의**:
  - 인장(Seal) 단독 사용 시: **중심 황금 홀씨 코어의 외경 반지름 ($X = 40px$, 전체의 10%)**.
  - 워드마크 단독 사용 시: **대문자 'M'의 전폭 및 높이 ($X = \text{Cap-height of 'M'}$)**.
  - 조합형 락업 사용 시: **워드마크 서브텍스트의 전고($1X$)**.
- **규정**: 사방 상·하·좌·우 최소 **$1X$ 이상의 완전한 빈 공간**이 확보되지 않으면 어떠한 레이아웃에서도 사용할 수 없습니다.

### 4.2. 매체별 광학적 크기 규격 (Optical Sizing Matrix)
축소 시의 뭉개짐(Anti-aliasing blur)을 방지하기 위해 뷰포트 크기별로 독립 작도된 전용 SVG 에셋을 사용합니다.

| 자산 구분 | 디지털 규격 | 인쇄 규격 (300DPI) | 광학 작도 파일 경로 및 특징 |

## Chapter 05. Color Architecture & 60-30-10 Budget

민들레와 소나기의 색채는 단순한 장식이 아니며, W3C 및 OKLCH 체계에서 도출된 **엄격한 광학적 대비비(Contrast Ratio)**를 따릅니다.

### 5.1. 전용 컬러 팔레트 스펙 (Master Color Palette)

```
[ Primary Palette: Architecture & Shield ]

 • Surface Dark:    #090d16  (RGB: 9, 13, 22)    - Elevated Containers & Cards
 • Surface Border:  #30363d  (RGB: 48, 54, 61)   - 2px Structural Crisp Stroke
 • Crisp White:     #ffffff  (RGB: 255, 255, 255) - Primary Headings

[ Accent Palette: Sonagi Catalysts ]
 • Sonagi Rain:     #4A90E2  (RGB: 74, 144, 226) - Dynamic Action Blue (30% Support)
 • Electric Cyan:   #00ffcc  (RGB: 0, 255, 204)  - High-Contrast Terminal Matrix
 • Dandelion Amber: #ffd166  (RGB: 255, 209, 102) - Warm Ambient Gold (10% Soul Core)
 • Dandelion Core:  #f59e0b  (RGB: 245, 158, 11) - Deep Amber Plume Root
```

### 5.2. 60-30-10 면적 배분 공식 (Area Allocation Budget)

```
┌────────────────────────────────────────────────────────┐
│  60% Canvas & Atmosphere : Deep Base (#060911)         │
├────────────────────────────┬───────────────────────────┤
│  30% Architecture & Border │ 10% Soul & Vitality       │
│  Sonagi Rain (#4A90E2)     │ Dandelion Amber (#ffd166) │
│  Slate Border (#30363d)    │ Electric Cyan (#00ffcc)   │
└────────────────────────────┴───────────────────────────┘
```

1. **60% Dominant (Canvas Base)**: 
   - 사용자의 시각적 피로를 없애고 고요한 아틀리에의 밤을 조성. 순수 블랙(`#000000`) 대신 미세한 청색조가 감도는 `#060911`을 전사 기본값으로 지정.
2. **30% Structural (Architecture & Rain)**: 
   - 2px 보더, 카드 컨테이너, 디바이더, 서브 카피. 이성적이고 차가운 엔지니어링의 신뢰성 제공.
3. **10% Accent (Soul & Vitality)**: 
   - 인장의 황금 홀씨 코어, 주요 CTA 버튼, 활성 토글. 차가운 구조 속에서 피어나는 다정한 온기를 상징.

## Chapter 06. Typography Hierarchy & Scaled System

민들레 생태계는 역사성과 장인정신을 대변하는 **세리프(Serif)**, 현대적 엔지니어링을 대표하는 **산세리프(Sans)**, 그리고 기계적 엄밀함을 나타내는 **모노스페이스(Mono)**의 3대 서체 패밀리를 공존시킵니다.

### 6.1. 서체 패밀리 배분 (Font Families)
1. **Primary Atelier Serif — `Cormorant Garamond`**:
   - 용도: 민들레 스튜디오 CI 워드마크, 인장 상단 원호, 포털 브랜드 슬로건 대형 Display.
   - 특징: 고전적인 가에치체 비례, 날카로운 세리프 마감, 고귀한 아틀리에 감성.
2. **Technical Engineering Sans — `Pretendard` / `Inter`**:
   - 용도: UI 전반의 본문, 카드 설명, 데이터 테이블, 모바일 화면.
   - 특징: 극상의 힌팅(Hinting)과 한글-영문 간 완벽한 베이스라인 정렬.
3. **Computational Monospace — `JetBrains Mono`**:
   - 용도: 인장 하단 스펙 표기(`EST. 2026`), 코드 블록, 토큰 값, 터미널 CLI 출력.
   - 특징: 0과 O의 명확한 구별, 코드 가독성에 최적화된 리가추어(Ligatures).

### 6.2. 6단계 타입 스케일 체계 (The 6-Step Type Scale)

```
[H1 Display]    64px  (Leading: 1.1,  Tracking: -0.02em,  Weight: 700 Serif/Sans)
  "겨울 끝, 민들레."
[H2 Section]    36px  (Leading: 1.2,  Tracking: -0.01em,  Weight: 700 Sans)
  "단단한 뿌리와 가벼운 삶"
[H3 Subhead]    24px  (Leading: 1.3,  Tracking: 0.00em,   Weight: 600 Sans)
  "Sovereign Atelier & Tools"
[Body Base]     16px  (Leading: 1.6,  Tracking: 0.00em,   Weight: 400 Sans)
  "단단한 경계와 맑은 도구로 당신의 쉼을 지킵니다."
[Caption Mono]  12px  (Leading: 1.4,  Tracking: +0.05em,  Weight: 500 Mono)
  "WINTER'S END, DANDELION • EST. 2026 • W3C TOKEN COMPLIANT"
[Micro Spec]    10px  (Leading: 1.2,  Tracking: +0.22em,  Weight: 600 Mono)
  "HEX: #060911 • AST: VECTORCRAFT_V1"
```

## Chapter 07. Visual Motifs & 2px Line Standards

민들레와 소나기의 디자인 언어는 "과도한 장식과 소프트 섀도우를 배제하고, 선명하고 정직한 물리적 선으로 경계를 규정"하는 **단단한 줄기선(The True 2px Stem)과 평면 조형**을 근간으로 합니다.

### 7.1. 2px 솔리드 스트로크 절대 원칙 (The True 2px Law)
- 모든 UI 카드, 버튼 외곽선, 아이콘 획은 **반드시 2px 솔리드 스트로크(`strokeWidth: 2`)**를 기본값으로 유지합니다.
- 거센 비바람 속에서도 꺾이지 않고 꼿꼿이 버틴 줄기와 잎맥처럼, 나를 지켜내는 선명한 경계선을 표현합니다.
- 1px 이하의 흐릿한 헤어라인(Hairline)은 렌더링 엔진 간 서브픽셀 앤티에일리어싱 뭉개짐을 유발하므로 금지합니다.
- (예외: 인장의 내부 보조 링 및 8각 패싯 굴절선에 한해 시각적 원근감을 위해 `1.5px` 허용).

### 7.2. 4단계 코너 라디우스 모듈러 스케일 (Corner Radius Scale)
- `radius-none (0px)`: 완전한 직각. 터미널 윈도우, 데이터 그리드 테이블.
- `radius-sm (4px)`: 기본 버튼, 뱃지, 입력 인풋창, 일반 카드.
- `radius-md (8px)`: 모달 다이얼로그, 피처드 패널 컨테이너.
- `radius-lg (12px)`: 소프트 서피스 래퍼, 시스템 알림 팝업.
- `radius-full (9999px)`: 상태 태그 캡슐, 알약형(Pill) 뱃지.

### 7.3. 8각 유리 문진 패싯 모티프 (Paperweight Facet Motif)
- 인장의 8각 기하학 패싯 선은 랜딩 페이지의 배경 워터마크, 3D 뷰어의 회전 와이어프레임, 제품 패키징의 단면도로 파생되어 일관된 '유리 공방'의 시각적 메타포를 형성합니다.

## Chapter 08. The 10 Golden Prohibitions (10대 금지 규정)

브랜드의 자의적 왜곡과 저품질 양산을 방지하기 위해, 다음 10가지 행위를 **영구적 헌법 위반**으로 규정하며 자동화 린터(`wiki_semantic_linter.py`) 및 PR 검수에서 즉시 차단합니다.

```
┌──────────────────────────────────────────────────────────────────────────────────┐
│                           THE 10 GOLDEN DON'TS MATRIX                            │
├──────────────────────────────────────────────────────────────────────────────────┤
│                                                                                  │
│   ❌ 01. 가로/세로 비례 왜곡 금지 (DO NOT STRETCH OR SKEW)                       │
│          종횡비를 무시하고 임의로 납작하게 늘리거나 찌그러뜨리는 행위.            │
│                                                                                  │
│   ❌ 02. 임의 각도 회전 금지 (DO NOT ROTATE)                                     │
│          인장이나 로고타입을 1도라도 기울여 대각선으로 배치하는 행위.             │
│                                                                                  │
│   ❌ 03. 비승인 색상 주입 금지 (DO NOT RECOLOR)                                 │
│          지정된 팔레트 이외의 임의 HEX 코드나 네온 핑크, 원색 빨강 적용.         │
│                                                                                  │
│   ❌ 04. 조잡한 드롭 섀도우 추가 금지 (NO DROP SHADOWS)                          │
│          인장이나 워드마크 외곽에 흐릿한 블러 그림자를 인위적으로 부착.           │
│                                                                                  │
│   ❌ 05. 저대비 배경 배치 금지 (NO LOW CONTRAST)                                 │
│          대비비 4.5:1 미만의 회색, 밝은 하늘색 배경 위에 흰색 로고 배치.          │
│                                                                                  │
│   ❌ 06. 복잡한 사진 위 무보호 배치 금지 (NO BUSY BACKGROUND)                    │
│          디테일이 복잡한 사진이나 텍스처 위에 보호 패널 없이 직접 얹는 행위.       │
│                                                                                  │
│   ❌ 07. 락업 비례 및 서체 임의 해체 금지 (DO NOT ALTER LOCKUP)                  │
│          인장의 크기를 극단적으로 줄이고 텍스트만 키우거나 서체를 임의 치환.     │
│                                                                                  │
│   ❌ 08. 2px 스트로크 두께 임의 변경 금지 (DO NOT ALTER STROKES)                 │
│          외벽 2px 링을 0.5px로 깎거나 5px로 두껍게 뭉개는 행위.                  │
│                                                                                  │
│   ❌ 09. 1X 안전 여백 침범 금지 (DO NOT ENCROACH CLEARSPACE)                     │
│          사방 1X 안전 여백 안쪽으로 다른 버튼, 카피, 프레임이 파고드는 행위.      │
│                                                                                  │
│   ❌ 10. AI 환각 슬롭 렌더링 금지 (NO AI SLOP HALLUCINATION)                     │
│          정밀한 SVG 벡터 대신 생성 AI의 모호한 비트맵 노이즈를 그대로 사용하는 것.│
│                                                                                  │
└──────────────────────────────────────────────────────────────────────────────────┘
```
